# 🌍 Django Booking Website
A simple web application for booking hotels in different countries.

The user can select a country and book a room of one of the categories: Deluxe, Family or Standard.

---

## 🚀 Functionality
- Select a country (4 options).
- View available hotels and rooms.
- Room categories: Deluxe, Family, Standard.
- Booking form with saving data in the database.

---

## 🛠 Tech stack
- **Backend**: Django, Django ORM
- **Database**: SQLite (default)
- **Frontend**: HTML, CSS (Bootstrap/Material Kit)
- **Other**: Git, Python 3.10+
